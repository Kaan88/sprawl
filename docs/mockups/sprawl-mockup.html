What the mockup shows

  • The whole window is acrylic: the moving wallpaper behind it stays visible through a blurred, tinted layer, and panels are lighter glass on top.
  • While scanning, the treemap builds itself as data arrives. A glass overlay shows the file-table read as a block map, live counters, throughput, and file types racing for the top spot.
  • When the scan finishes, a wave runs across the map. Tiles are lit boxes with cushion shading. The one under the cursor rises and glows, its folder lifts with it, and nearby tiles ripple.
  • Folder names sit on the map like WizTree's. Clicking a tile zooms into its folder, and every tile glides to its new place.

How it maps to WinUI 3

  • Window: DesktopAcrylicBackdrop as the system backdrop, with an extended title bar and translucent AcrylicBrush cards.
  • Treemap: a SwapChainPanel drawn with Direct3D 11. Each tile is an instanced box, lighting runs in a pixel shader, labels use DirectWrite, and it animates at the display's refresh rate.
  • Scan: the drive's file table is read directly when running as admin, otherwise a multi-threaded folder walk. Progress is polled every frame to drive the overlay.
  • Tables: virtualized lists with sortable columns and right-click menus, so millions of rows stay smooth.
