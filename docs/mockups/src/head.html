Sprawl design gallery

Thirty-six mockups for Sprawl, a Windows disk-space analyser: from small polish edits up to new branding. Each is drawn with WinUI 3 controls and Fluent 2 spacing (4 and 8 px radii, 32 px controls, Segoe UI Variable). Sample data is invented. Where a piece is not a stock WinUI control it is marked custom, with a note on how to build it. Every deletion path keeps the review step and says what is permanent.
