# Astra review for 1.0.10, round 1 (2026-11-26)

**Hold 1.0.10.** I found paths where a saved **Never touch** choice can be lost or ignored, and where an external cleanup can act on a different target from the one reviewed.

### Blocker

| # | Location | Concrete failure and fix |
|---|---|---|
| B1 | `crates/sprawl/src/wizard.rs:1357–1366`; `crates/sprawl-advisor/src/clean.rs:274–277,316–318` | **A Keep can be accepted but not enforced.** Settings accepts any absolute path for which `is_file` or `is_dir` succeeds and saves its spelling. A valid Windows short name for a folder can therefore be saved as kept, while Delete and Compress compare the scanned long name using only case and separator normalization. An already-scanned file under that folder can still be recycled or compressed. **Fix:** store the checked long path; resolve existing entries at the action boundary and refuse ambiguous or unresolvable aliases. |
| B2 | `crates/sprawl/src/advisor.rs:3143–3155`; `crates/sprawl/src/wizard.rs:1361–1366` | **Saving Advisor memory can erase another window’s Keep.** Two windows can both read the same `memory.toml`, add different Keeps, then replace the file successively. The last writer drops the other Keep. A failed re-read also falls through to saving the stale in-memory copy. Settings then says “Sprawl will never offer …” without knowing whether the save succeeded. **Fix:** lock the entire read–merge–replace operation, abort on read failure, and return the result to Settings before displaying success. |
| B3 | `crates/sprawl/src/advisor.rs:2490–2499`; `crates/sprawl/src/cleanup.rs:928–931,1053–1061` | **Compression and Undo can ignore a newly saved Keep.** Window B keeps a child of a compressed game; window A, already open, starts Undo using only A’s in-memory Keep list. The worker never loads B’s protection. Similarly, compression queued behind another cleanup uses the batch-start Keep list when its turn arrives. **Fix:** reload the checked Keep list at worker dispatch, union it with protections already seen, and refuse if it cannot be read. |
| B4 | `crates/sprawl-advisor/src/external_tool.rs:103–110,192–197,216–225` | **Recycle Bin consent is bound to drive letters, not volumes.** Review with removable disk A at `E:`; replace it with disk B at `E:` before starting. Scope equality still succeeds, because the strings and letters are unchanged. The command targets B’s bin, which was never reviewed. **Fix:** include volume identity in the receipt, revalidate it at dispatch, and omit or refuse removable targets if execution cannot be bound to that volume. |
| B5 | `crates/sprawl-advisor/src/versions.rs:213–227`; `crates/sprawl-advisor/src/external_tool.rs:103–110,152–159` | **The nvm scope can change after the final check.** Sprawl reads `settings.txt` to establish nvm’s `root` and `path`, releases the file, and holds only the version folder’s parent across launch. A settings rewrite between validation and nvm’s own read leaves the reviewed scope unchanged in Sprawl but changes the configuration the uninstall consumes. **Fix:** hold the validated settings file against writes and replacement through execution, or hold back this command when its targets cannot be bound independently of that file. |

### Should fix

| # | Location | Concrete failure and fix |
|---|---|---|
| S1 | `crates/sprawl/src/advisor.rs:4385–4389,4426–4430`; `crates/sprawl-advisor/src/dupes.rs:306–325` | **The interrupted-link recovery notice offers Delete.** It is an `Info` finding with no command; its path is the *first* `.sprawl-original`, potentially the only file left under either name. The existing second-click cleanup explicitly excludes this notice (`cleanup.rs:477–480`), but the new button does not. Confirmation names the file, so this is not a silent deletion. **Fix:** exclude recovery notices from both button rendering and dispatch; retain **Show in tree**. |
| S2 | `crates/sprawl-advisor/src/remedies.rs:181–197,495–497,598–601` | **Compression does not re-establish why a folder qualified.** Discovery requires executable and sibling-library evidence for `Origin::Other`. At execution, `policy.scope(path)?` can return `Other`, and the result is discarded. If a detected game directory is replaced by an ordinary data folder at the same path after review, the live walker can compress the replacement. **Fix:** bind the reviewed directory identity and recheck origin-specific eligibility before planning files. |
| S3 | `crates/sprawl/src/wizard.rs:120–138`; `crates/sprawl-advisor/src/remedies.rs:444–448,598–601`; `crates/sprawl-advisor/src/safety.rs:1034–1039` | **A personal-data folder can qualify as a program library.** The picker rejects the profile root but accepts Documents. A large text-only child then qualifies without an executable because its parent is configured. The later safety pass raises the risk to Orange; it does not withdraw the program-compression suggestion. **Fix:** reject known personal-data roots as library entries, including redirected ones, and apply the same rule to previously saved entries. |
| S4 | `crates/sprawl/src/advisor.rs:2490`; `crates/sprawl-advisor/src/remedies.rs:37–42`; `crates/sprawl/src/cleanup.rs:1332–1338` | **Two supported compression choices cannot be undone in the app.** XPRESS4K and LZX are offered and recorded, but Undo accepts only `xpress8k` and `xpress16k`. **Fix:** use the same algorithm parser for selection, recording, and Undo. Also align Steam eligibility: discovery accepts the `steamapps\common` layout, while Undo additionally requires current Steam registration (`remedies.rs:82–85,476–496`). |
| S5 | `crates/sprawl-advisor/src/config.rs:149–160`; `crates/sprawl/src/wizard.rs:1702–1710,1732–1744` | **The shared AI editor can overwrite unrelated changes.** It saves the entire opening snapshot of `ai.toml`. If B adds a provider while A’s editor is open, A changing reasoning effort can erase B’s provider. A malformed config also loads as defaults and can be replaced on the next AI edit. Credential writes and removals still proceed if the config save fails. **Fix:** distinguish missing from unreadable config, merge edited fields under a lock, and gate dependent credential changes on a successful config save. |

**Checks that held in the source trace:** Advisor Delete compares the finding path to the current node, passes `permanent = false`, and checks tree generation again after confirmation. Read-only mode, CSV trees, filtered folders, and multi-root top-level nodes have explicit refusals; a single scan root also fails the post-confirmation check. Settings Cancel reaches the password-box clear and pending model-lookup reset. External cleanup has no generic raw-command fallback.
